# S1 方案概要

> 参赛队：RMD　赛题：A11《AI 模拟面试与能力提升软件》　组别：本科生组（应用类）
## 一、要解决的问题

求职者练面试长期缺三样东西：真实追问、有依据的反馈、岗位针对性的训练。通用 AI 能问问题，但题目与简历无关，评分只有一句「表达流畅」。

本作品把主档、简历、岗位、面试、练习五类实体打通，AI 对每一类都有读写路径，写操作经审批与版本，让模拟面试可追溯、可评估、可提升。

## 二、方案概述

岗位化题库与知识库驱动多轮模拟面试，产出有证据的评估报告，再把薄弱项变成下一轮练习。

1. 岗位化题库与知识库：岗位维度可扩展——题库、知识库与量表按岗位组织，当前落地 Java 后端、Web 前端两个目标岗位为样本，新增岗位按同一口径补齐语料与题目即可；知识库为词法检索（BM25），出题以命中片段为据并写出处，未命中标「依据不足」。
2. 多模态面试：文字与语音双通道，转写供本人核对；链路不可用时降级为文字并保留上下文，面试官按要点追问。
3. 结构化评估：内容评技术正确性、知识深度、逻辑严谨性、岗位匹配度，表达评语速、清晰度、自信度；量表冻结并逐维度附证据，纯文本场次不虚构音频指标。
4. 提升闭环：薄弱维度生成练习计划与复测入口，按同岗位同量表口径绘制成长曲线。

## 三、实施路径

- 系统基础能力：Resume、Profile、JD 三类事实数据与版本流、Patch 与 Diff 审批、Agent 运行时与执行模式、多模型接口与密钥托管、权限与访问审计、React 前端与双语界面。
- 面试与能力提升能力：岗位题库与知识库（本地知识库资料随作品提交）、面试官 Agent 与追问、语音与文字双通道、评估报告与成长曲线、岗位笔试。
- 下一阶段：BM25 + 向量检索（RAG）+ rerank 重排、扩充岗位覆盖、更低延迟实时语音、可选的数字人表现层。

团队三角色：队长（产品与开发）管产品定义、核心开发、验收与成本复核，开发管部分开发、接口联调、模块自测与成本模型，测试管用例、缺陷回归与端到端走查；三人同一仓库协作，按里程碑提交原型、接口契约与测试证据。

## 四、预期效果

面试从「一问一答」变成「有据可查的训练」：每个分数能追到原话，每个薄弱项有下一步练习，进步能同口径对比。
