## 复核方式

- 提交：在包根执行 \`git show <修复提交> --stat\`（源码包用 \`git archive HEAD\` 生成，历史提交在包内的 \`.git\` 中不包含；如需查历史，请在对应 worktree 执行）。
- 用例：\`cd backend && .venv/bin/python -m pytest -q tests/<文件>\`；\`cd ui && pnpm exec vitest run <文件>\`；\`cd agent-core && uv run pytest -q tests/<文件>\`。
- 门禁：\`node quality-gates/gates/no-fake-implementation.js .\` 与 \`node --test quality-gates/tests/no-fake-implementation.test.mjs\`。
- 用例全量底表见 02-测试用例清单.md（脚本 \`tools/extract-test-cases.py\` 生成）。
