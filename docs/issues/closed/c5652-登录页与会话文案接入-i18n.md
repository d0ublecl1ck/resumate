# 登录页与会话文案接入 i18n

## Background

main 合入 i18n 双语与 `ui-i18n` 质量门禁后，所有用户可见文案必须走翻译键。本 worktree 的登录页与会话相关文案（登录/注册、字段、错误、会话校验、导航用户区与登出）此前是硬编码中文，不满足新约定。

## Scope

- 新增 `auth` 命名空间（zh-CN / en），覆盖登录、注册、字段、动作与错误文案。
- `nav` 命名空间补充 `role.admin`、`role.anonymous`、`actions.logout`。
- `LoginForm`、`LoginPage`、`RequireAuth`、`AppNav` 与登录 stories 全部改用 `t(...)`。
- 合并 main 时解决 `app-nav.tsx` 冲突：保留 main 的 i18n 导航标签 + 本分支的当前用户与登出。

## Non-goals

- 不改交互逻辑、接口与路由。
- 不翻译用户内容/后端数据。
- 不新增语言，除 zh-CN/en 外不做扩展。

## Acceptance Criteria

- [x] zh-CN 与 en 的 `auth` 词条键结构一致，en 资源无残留中文。
- [x] 登录/注册/字段/错误/会话校验与导航用户区、登出文案全部走 i18n。
- [x] 组件与页面无硬编码中文界面文案（`ui-i18n` 门禁通过）。
- [x] `pnpm -C ui test`、`lint`、`build` 与 `archkit inspect .` 通过。

## Implementation

- 词条：新增 `ui/src/i18n/locales/zh-CN/auth.ts` 与 `en/auth.ts`，并在两个 `index.ts` 注册；`nav.ts` 补充角色与登出词条。
- 组件：`login-form.tsx`、`login.tsx`、`require-auth.tsx`、`app-nav.tsx` 全部改用 `useTranslation()`；`login.tsx` 的模块级错误映射使用 i18n 单例；`login-form.stories.tsx` 通过 `useTranslation` 包装渲染，不再内联中文字面量。
- 合并：将 main 合入本分支，仅 `app-nav.tsx` 冲突，按「main 的 i18n 标签 + 本分支用户区/登出」保留双方语义。

## Verification

- `pnpm -C ui test`：8 个文件 42 passed（含 i18n 键结构与 en 无中文测试）。
- `pnpm -C ui run lint`：0 warnings / 0 errors。
- `pnpm -C ui run build`：通过。
- `archkit inspect .`：Quality gates passed（`ui-i18n` 通过：键结构一致、en 无残留中文、components/pages 无硬编码文案）。
