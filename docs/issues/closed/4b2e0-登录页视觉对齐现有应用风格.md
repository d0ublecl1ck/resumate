# 登录页视觉对齐现有应用风格

## Background

b5530 的登录页使用了色块光斑与硬偏移阴影，与现有应用（`card-soft`、`bg-primary`、`font-serif`、coral 错误色、cobalt 强调色）的克制风格不一致。用户要求对齐正在运行的应用界面。

## Scope

- 重写 `login-form.tsx` 的视觉：去掉色块光斑与硬偏移阴影。
- 复用应用现有语言：导航同款品牌标记（`size-9 rounded-lg bg-primary` + Sparkles）、`card-soft` 卡片、`bg-primary` 主按钮、`border-input` 输入、coral 错误提示、cobalt 链接。
- 保持登录/注册/提交中/错误状态与可访问性不变。

## Non-goals

- 不改交互逻辑、接口与路由。
- 不改其它页面，不引入新的设计令牌。
- 登录页仍不在 `ui/prototypes/index.html` 覆盖范围内，原型确认留待后续。

## Acceptance Criteria

- [x] 登录页品牌标记、卡片、按钮、输入、错误色与现有应用一致。
- [x] 去除色块光斑与硬偏移阴影。
- [x] 登录/注册/错误/提交中状态保持可用，既有测试保持通过。
- [x] `pnpm --dir ui run build`、`test`、`lint` 与 `archkit inspect .` 通过。

## Implementation

- `ui/src/components/login-form.tsx`：移除三个 `blur-3xl` 装饰光斑与 `shadow-[...]` 偏移阴影；品牌区改为与 `app-nav` 一致的 `size-9 rounded-lg bg-primary` + Sparkles；表单容器改为 `card-soft p-6`；错误提示由 destructive 改为 `border-coral/40 bg-coral/10 text-coral`；按钮改为应用主按钮样式；输入与标签沿用 `border-input` / `text-muted-foreground`。
- Storybook stories 无需改动，HMR 自动反映新样式。
