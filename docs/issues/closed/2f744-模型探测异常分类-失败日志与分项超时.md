# 模型探测异常分类、失败日志与分项超时

## Background

`backend/app/modules/settings/catalog.py` 的 `probe_connection` 用 `except httpx.HTTPError:` 把所有传输层异常统一映射为同一句 `无法连接模型服务，请检查 Endpoint 与网络`，且不写任何日志：连接失败与读 / 写 / 池超时无法区分，事后也无法排查。另外 `PROBE_TIMEOUT_SECONDS = 5.0` 是覆盖整个 `/chat/completions` 往返的单一硬超时，对推理类模型（例如 deepseek 默认 effort=high）偏短，慢请求被截断后仍提示「无法连接」，把超时误报成网络不可达。

## Scope

- 在 `catalog.py` 拆分传输层异常：`httpx.ConnectError` / `httpx.ConnectTimeout` 保留原文案 `无法连接模型服务，请检查 Endpoint 与网络`；其余 `httpx.TimeoutException`（读 / 写 / 池超时）返回新文案 `模型响应超时，请稍后重试`；其它 `httpx.HTTPError` 保留网络文案。捕获顺序必须先 `ConnectError` 再 `ConnectTimeout` 再 `TimeoutException`。
- 每次传输层失败新增一条 `logger.warning`，记录探测 URL（`base_url + CHAT_COMPLETIONS_PATH`）与 `type(exc).__name__`；绝不记录 api_key、Authorization 头或任意请求头 / 请求体。
- 把单一 float 超时改为分项 `httpx.Timeout(connect=5.0, read=30.0, write=10.0, pool=5.0)`，保持 `timeout` 与 `client` 形参可注入。

## Non-goals

- 不改数据库、不改任何模型配置、不改 provider 白名单与 HTTP 状态码文案映射。
- 不改 `ui/` 任何文件。
- 不引入新依赖（不新增 loguru，使用标准库 logging）。
- 不改 `probe_connection` 的返回类型与参数签名，`service.test_model_connection` 调用路径保持可用。

## Acceptance Criteria

- [x] `ConnectError` / `ConnectTimeout` 与 `ReadTimeout` / `WriteTimeout` / `PoolTimeout` 返回不同文案：前者保留 `无法连接模型服务，请检查 Endpoint 与网络`，后者为 `模型响应超时，请稍后重试`。
- [x] 每次传输层失败都触发 `logger.warning`，日志含探测 URL 与异常类名，且不含 api_key / Authorization / 请求体。
- [x] 默认超时为分项 `httpx.Timeout`，`read` 明显大于 5s；注入 `client=` 与 `timeout=` 的既有行为不变。
- [x] `cd backend && uv run pytest tests/test_model_catalog.py tests/test_settings.py -q` 与全量 `uv run pytest -q` 全绿。
- [x] `archkit inspect .` 通过。

## Implementation

- `backend/app/modules/settings/catalog.py`：
  - 新增 `import logging` 与模块级 `logger = logging.getLogger(__name__)`；传输层失败按分支调用 `logger.warning("…：url=%s error=%s", url, type(exc).__name__)`，只写探测 URL 与异常类名，不含 api_key、Authorization、请求头或请求体。
  - 拆开单一 `except httpx.HTTPError`：先 `except (httpx.ConnectError, httpx.ConnectTimeout)` 返回 `无法连接模型服务，请检查 Endpoint 与网络`；再 `except httpx.TimeoutException` 返回新文案 `模型响应超时，请稍后重试`；最后 `except httpx.HTTPError` 返回网络文案。顺序保证 `ConnectTimeout`（`TimeoutException` 子类）先归入 connect 分支。
  - 把 `PROBE_TIMEOUT_SECONDS = 5.0` 换成 `PROBE_TIMEOUT = httpx.Timeout(connect=5.0, read=30.0, write=10.0, pool=5.0)`；`probe_connection` 形参改为 `timeout: httpx.Timeout | float = PROBE_TIMEOUT`，`client=` 注入路径不变。
- `backend/tests/test_model_catalog.py`：新增 9 条用例（connect 与 read / write / pool 文案区分、connect 与 read 文案不相等、失败日志含 url + 类名且不含密钥、默认分项超时、显式 float 超时仍可用）。
- `README.md`：后端测试计数 `238 passed` → `247 passed`。
- `.freak`：登记三条待复核线索（探测日志尚无 logging 配置、HTTP 408 文案与新传输超时文案并存、分项超时属经验取值）。
