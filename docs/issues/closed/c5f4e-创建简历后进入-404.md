# 创建简历后进入 404

## Background

用户在工作台打开「创建简历」、以表单方式填完并提交后，直接落到「未找到该简历 / 它可能已被删除或从未存在。错误码：404」状态页。

只读定位：`ui/src/components/create-resume-modal.tsx:46-50` 的 `submit()` 是演示桩，只 `navigate("/resumes/res_fe_lead")`，注释也写明「真实实现会调用 POST /resumes」；`res_fe_lead` 只存在于前端 mock `ui/src/lib/content.ts`，后端无此记录。`ui/src/lib/api.ts` 没有 createResume 客户端函数，而后端 `POST /resumes`（`backend/app/modules/resume/api.py:56`）已可用。于是进入 `/resumes/res_fe_lead` 后 `GET /resumes/res_fe_lead` 返回 404，`ui/src/pages/resume-editor.tsx:28` 渲染 `ui/src/pages/states.tsx` 的 notFound 状态。

## Scope

- `ui/src/lib/api.ts`：新增 `createResume`，走真实 `POST /resumes`，沿用既有 `request<T>` 约定与 `METHOD + path` 注释格式。
- `ui/src/components/create-resume-modal.tsx`：form 方式改为真实调用；提交中禁用按钮并给出加载态；成功后用后端返回 id 跳转并失效简历列表相关查询键；失败时就地用 i18n 文案报错，禁止直出后端 message。
- chat / profile 方式保留原有「预览创建摘要」交互，但后端 Agent 创建能力未就绪时明确提示未接入，不再假装成功跳转到不存在的简历。
- i18n：新增文案键，zh-CN 与 en 结构一致，en 无中文。
- 测试：先用现有 MSW 栈写失败用例（断言 POST /resumes 发出且跳转到返回 id），再实现到绿。

## Non-goals

- 不改后端接口契约，不新增后端端点（`POST /resumes` 已存在）。
- 不实现 chat / profile 的 Agent 创建链路（后端能力缺失，仅报告）。
- 不改简历库 / 编辑器的既有视觉与路由结构。

## Acceptance Criteria

- [x] 表单创建会发出 `POST /resumes`，请求体含 title / templateId / targetRole。
- [x] 创建成功后跳转到后端返回的 `id`，`GET /resumes/{id}` 返回 200 且不再渲染 404 状态。
- [x] 提交中创建按钮禁用并显示加载态。
- [x] 创建失败时就地展示 i18n 文案，不含后端原始 message，且不发生跳转。
- [x] chat / profile 明确提示 Agent 创建未接入，不发送创建请求也不跳转。
- [x] 成功后失效简历列表相关查询键。
- [x] zh-CN 与 en 键结构一致，en 无残留中文。
- [x] `pnpm -C ui test`、`archkit inspect .` 通过。

## Implementation

- `ui/src/lib/api.ts`：新增 `createResume({ title, templateId, targetRole, tags, profileId })`，`POST /resumes`，返回 `Resume`。请求体用 camelCase，与后端 `ApiModel(alias_generator=to_camel)` 的线上契约一致。
- `ui/src/components/create-resume-modal.tsx`：
  - form 方式 `await createResume(...)`；提交中 `disabled` + `aria-busy` + 「创建中…」加载态。
  - 成功后 `invalidateQueries({ queryKey: ["resumes"] })` 与 `["workbench-summary"]`，再跳转到 `/resumes/{created.id}`。
  - 失败走 `createErrorMessage`：按机器错误码映射 `resume.create.errors.{validation,permission,network,generic}`，不拼后端 message；错误用 `role="alert"` 就地展示。
  - chat / profile 保留「预览创建摘要」按钮，点击后用 `role="status"` 提示 `resume.create.agentNotAvailable`，不发请求、不跳转。
- i18n：`ui/src/i18n/locales/{zh-CN,en}/resume.ts` 新增 `create.submitting`、`create.agentNotAvailable`、`create.errors.{validation,permission,network,generic}`，键结构一致。
- 测试：新增 `ui/src/components/create-resume-modal.test.tsx`，含 App 级集成（真实路由 + MSW，验证不再 404）与组件级（失效查询键、提交态、失败文案、chat/profile 未接入）。
- README：UI 测试口径由 `21 files / 165 passed` 更新为 `22 files / 171 passed`。
