# 简历库卡片徽标保持右上角并登记英文折行边界

## Background

简历库卡片（c9d57 落地）把保存状态徽标放在标题行右上角。1280 宽三列时卡片内宽 267px：英文 `Uncommitted` 徽标占 118px，中文「未提交」只占 78px，于是英文标题只剩 141px，而 9 个汉字的标题需要 162px，差 21px 折到第二行；中文恰好不折。实测英文 6 张卡标题全部 2 行、卡高 327，中文全部 1 行、卡高 299。

曾实现过「徽标下移到元信息区、标题独占整行」（中英文都不折且卡片等高 335px），但用户认为徽标在右上角更符合直觉，予以否决。

## Scope

- 保持徽标在标题行右上角：组件与断点零改动。
- 在原型 `ui/prototypes/index.html` 的 SCR-002 章节登记这条已知边界与实测数字，避免下次被当成新缺陷重查。

## Non-goals

- 不改卡片标题字号、不改徽标文案、不改三列断点。
- 备选修法 A/B/C 中的 B（三列断点挪到 `2xl`）与 C（标题降 16px 且卡片内徽标去图标）本轮都不做，只在原型登记备查。

## Acceptance Criteria

- [x] 徽标仍在标题行右上角，组件与断点零改动。
- [x] 原型登记已知边界（英文折行的实测宽度与原因），并给出备选修法方向。
- [x] `pnpm -C ui test`、`pnpm -C ui build`、`archkit inspect .` 通过。

## Implementation

- 决策：三个方案里选 A —— 接受英文标题折行，换取徽标留在右上角。
- `ui/prototypes/index.html`：SCR-002 章节补「已知边界」一句（英文 `Uncommitted` 118px vs「未提交」78px；1280 三列标题只剩 141px、需要 162px），卡片结构说明补「右上角保存状态」。
- 组件零改动：`ui/src/components/resume-library.tsx` 与 c9d57 提交时完全一致。
- 备选修法（未采用，登记备查）：B 三列断点挪到 `2xl`(1536)，1280–1535 用两列；C 卡片标题 18px 降到 16px 且卡片内徽标去掉装饰图标（实测可用 163px / 需要 144px，余量 19px）。

## Verification

- 实测（headless，1280 宽 / 三列 / `deviceScaleFactor=2`）：英文 6 张卡标题全部 2 行、卡高 327px；中文全部 1 行、卡高 299px；徽标位置在标题行右上角。
- `pnpm -C ui test` → `Test Files 34 passed (34)`，`Tests 254 passed (254)`。
- `pnpm -C ui build` → `✓ built`。
- `archkit inspect .` → `Quality gates passed.`
