# README 增加待办章节并登记新用户引导

## Background

README 已有「已知边界」清单，但它是「明确不做或长期缺口」的登记处，没有地方记录「已经确认要做、只是排在后面」的事项。

「新用户引导」（首次进入的引导流程与空态引导）已确认要做，但用户明确要求排在全部功能完成之后。它需要一个稳定的登记位置，否则只存在于对话里，下一个人或下一次会话看不到。

## Scope

- 在 README 增加 `## 待办（TODO）` 章节，位置在 `## 已知边界` 之后、`## 文档索引` 之前。
- 在其中登记「新用户引导」，并写明其前置条件为全部功能开发完成。
- 在章节内写明与「已知边界」的分工，避免两节内容重叠。

## Non-goals

- 不实现新用户引导本身。
- 不改动「已知边界」的既有条目。
- 不改动任何代码、测试、依赖或 i18n 词条。

## Acceptance Criteria

- [x] README 新增 `## 待办（TODO）` 章节，位置在 `## 已知边界` 之后。
- [x] 该章节登记「新用户引导」，并写明前置条件为全部功能开发完成。
- [x] 章节内写明与「已知边界」的分工，两节不重复。
- [x] `archkit inspect .` 通过。

## Implementation

`README.md` 在「已知边界」与「文档索引」之间新增 `## 待办（TODO）` 章节，登记一条待办：

- **新用户引导** —— 首次进入的引导流程与空态引导；前置条件为全部功能开发完成。

章节内同时写明与「已知边界」的分工（那里放「明确不做或长期缺口」，这里放「已承诺要做、只是排在后面」），避免两节内容重叠。
