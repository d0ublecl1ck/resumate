# 撰写 A11 参赛材料 S1 方案概要与 S2 解决方案

## Background

团队 RMD 参加 2026「数字马力杯」第十三届浙江省大学生服务创新应用大赛，赛题 A11《AI 模拟面试与能力提升软件》（命题企业：锐捷网络，本科生组，应用类）。省赛复赛为网络评审，需提交 S1 方案概要（正文 ≤800 汉字）与 S2 解决方案（S2A–S2D 四节，每节标注负责人角色）。

本仓库现有基座是「Profile 存事实、Resume 为岗位投影、JD 记录岗位需求」的可审阅可回滚版本流：FastAPI 后端、Patch/Diff/Working Copy/Version/审批机制、Agent Runtime 与 SSE 轮次事件、PAT 与 RBAC 审计、React 19 前端。面试与能力提升（Epic 14、PRD 流程 F）在产品定义中已登记为 EXT 扩展，代码中尚无面试模块实现。

本 issue 产出两份参赛文稿，用于向评委说明方案与实施路径，且必须严格区分「现有基座」「本期新增」「下一阶段」。

## Scope

- 新增 `docs/competition/zj-fwwb-2026/S1-方案概要.md`：正文 ≤800 汉字，文末标注实际字数与「依据与素材」小节。
- 新增 `docs/competition/zj-fwwb-2026/S2-解决方案.md`：S2A 目标与服务模型 / S2B 组织管理与业务分析方案（项目经理负责）/ S2C 技术路线及实现方案（技术经理负责）/ S2D 成本模型及可行性分析（客户关系经理负责），文末「依据与素材」小节。
