# 简历编辑器空闲自动保存与设置项

## Background

契约 C-05 早已冻结了「输入即同步服务端缓冲 + 静默计时到期 flush 成一个 source=manual 版本 + 可关闭自动保存」的语义，但实现只有手动 flush（39b22 才刚接上），既没有自动保存，也没有服务端草稿缓冲，设置的自动保存开关也只存着不用（标签还写死「30s 静默提交」）。

本次按用户要求把静默时长做成可配置，默认 10 秒（C-05 原文是 30 秒，已同步改契约），并把草稿缓冲落到后端。

## Scope

- 后端：`resumes` 加草稿缓冲列（`draft_document` / `draft_base_version_id` / `draft_updated_at`，与 Agent 的 `working_*` 分离）+ alembic 迁移；`PUT /resumes/{id}/draft` 只同步内容不建版本，响应带 `draft`；`PUT /resumes/{id}/document` 提交时消费草稿缓冲。
- 后端设置：偏好新增 `autosave_interval_seconds`（默认 10，`ge=3 le=120`），随 `/settings` 读写。
- 前端：`lib/autosave.ts`（边界常量 + `clampAutosaveSeconds` + `useIdleAutosave` 静默计时 hook）；编辑器接草稿同步（停顿 1.5s）、静默到期自动 flush、倒计时展示、离开页面立即 flush、重开页面优先展示服务端草稿。
- 前端设置：`/settings` 的「个人偏好」加分区间隔输入（关闭自动保存时禁用，越界由后端 422 兜底）。
- 原型与文档：`#screen-editor`、`#screen-settings` 同步；契约 C-05 的 30 秒改为「默认 10 秒，可调 3–120 秒」；README 现状表与测试计数更新。

## Non-goals

- 不做 `beforeunload` 浏览器级未保存提醒（登记在 `.freak`）。
- 不做导出（后端无端点，仍是已知缺口）。
- 不改 Agent 的 working copy 链路：两条编辑链路各自持有基线（C-05 明确要求）。

## Acceptance Criteria

- [x] `PUT /resumes/{id}/draft` 写入后 `saveState=synced_draft`、`draft` 回显内容，且**不新增版本、不改 currentVersionId、不动已提交文档**。
- [x] 草稿基线与当前版本不一致时返回 409 `BASE_VERSION_STALE`。
- [x] `PUT /resumes/{id}/document` 提交后清空草稿并生成新版本。
- [x] 偏好 `autosaveIntervalSeconds` 默认 10，可保存 30，越界（2 / 121）返回 422。
- [x] 前端静默计时按设置走，输入重置计时，到期自动 flush 成 manual 版本。
- [x] 关闭自动保存时不倒计时、草稿仍进服务端缓冲、手动 flush 仍有效。
- [x] 原型两屏同步；契约与 README 同步；`pnpm -C ui test`、`pnpm -C ui build-storybook`、`uv run --directory backend pytest`、`archkit inspect .` 全部通过。

## Implementation

- `backend/app/modules/resume/models.py`：新增 `draft_document` / `draft_base_version_id` / `draft_updated_at`；注释说明与 `working_*` 的分工。
- `backend/migrations/versions/b3d8e1f4a6c9_add_manual_draft_buffer.py`：加列迁移，`down_revision` 指向当时的最新 head `e3a1c7d9b2f4`（第一版误挂在 `f7b1c3e5a9d2` 上，`test_migrations.py` 报 multiple heads 后修正）。
- `backend/app/modules/resume/schemas.py`：`DraftUpdate`；`ResumeResponse.draft`。`service.py`：`save_draft`；`update_document` 先清缓冲再走原有「内容未变则不建版本」的短路，短路时若确有草稿也会提交清理并刷新 `updated_at`。
- `backend/app/modules/resume/api.py`：`PUT /resumes/{resume_id}/draft`，权限沿用 `resume:write`。
- `backend/app/modules/settings/{schemas,service}.py`：`autosave_interval_seconds`（默认 10、区间 3–120）读写；偏好走 JSON 列，无需迁移。
- `ui/src/lib/autosave.ts`：`DEFAULT_AUTOSAVE_SECONDS=10`、`MIN=3`、`MAX=120`、`clampAutosaveSeconds`、`useIdleAutosave`（250ms tick，`revision` 变化即重置）。
- `ui/src/components/resume-editor.tsx`：偏好查询取开关与秒数；停顿 1.5s 同步草稿；静默到期 `flush(t("resume.editor.autosaveMessage"))`；`dirty` 含 `synced_draft`；`leaveRef` + 卸载时 fire-and-forget flush；初始文档优先取 `resume.draft`。
- `ui/src/components/settings-form.tsx`：间隔数字输入，`clampAutosaveSeconds` 收敛后随偏好一起 PATCH。
- `ui/src/mocks/handlers.ts`：补 `PUT /api/resumes/:id/draft`，镜像后端乐观锁与「不建版本」行为，供 Storybook 与测试共用。
- 原型 `#screen-editor`（倒计时 + 草稿缓冲状态清单）与 `#screen-settings`（个人偏好分区 + 间隔输入）；Storybook 新增 `AutosaveOn` / `AutosaveOff` / `AutosaveLongInterval` 与设置页 `AutosaveOff`。
