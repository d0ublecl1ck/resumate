# 前端登录页与会话接入

## Background

后端 Opaque Token 会话认证（b6708）已落地，但前端没有登录入口与会话状态，所有业务页面仍假设已登录。定稿原型 `ui/prototypes/index.html` 只覆盖首页，未覆盖登录页；按 AGENTS 约定，本工单沿用原型设计令牌（card-frame、primary/coral/cobalt/gold、focus ring）与既有输入样式，并将登录页视觉记为待原型确认项，不自行引入新的视觉规则。

## Scope

- `ui/src/lib/types.ts`：新增 `AuthUser`，扩充 `MachineErrorCode`（UNAUTHENTICATED/INVALID_CREDENTIALS/ACCOUNT_BANNED/FORBIDDEN/EMAIL_ALREADY_REGISTERED）。
- `ui/src/lib/api.ts`：新增 `getCurrentUser`、`login`、`register`、`logout`。
- 会话接入：`useCurrentUser` 查询、`RequireAuth` 路由守卫、`/login` 路由；已登录访问 `/login` 跳转首页。
- `LoginForm` 表现层组件（登录/注册、提交中、错误）与 `LoginPage` 容器。
- `app-nav` 展示当前登录用户并提供登出。
- MSW handlers 与组件/路由测试。
- 初始化 Storybook（`.storybook/`、scripts、依赖）并编写登录页 stories。

## Non-goals

- 不改后端、不新增后端端点。
- 不实现找回密码、邮箱验证、Remember Me、会话列表与多设备管理。
- 不引入原型未记录的新视觉规范；登录页视觉待原型确认。
- 不做 i18n 与深色主题专项适配。

## Acceptance Criteria

- [x] `/login` 可用邮箱密码登录，成功后进入工作台；已登录访问 `/login` 跳转首页。
- [x] 支持注册模式，注册成功即登录。
- [x] 未登录访问业务路由重定向 `/login`；401 等错误以统一信封文案提示。
- [x] 导航展示当前用户并可登出，登出后回到 `/login`。
- [x] 登录页覆盖加载、凭据错误、封禁错误状态且可键盘操作。
- [x] MSW handlers 与组件/路由测试通过。
- [x] Storybook 可启动，登录页 stories 覆盖登录/注册/提交中/错误。
- [x] `pnpm --dir ui run build`、`test`、`lint` 与 `archkit inspect .` 通过。

## Implementation

- 接口与契约：`lib/types.ts` 新增 `AuthUser` 与认证错误码；`lib/api.ts` 新增 `getCurrentUser/login/register/logout`。
- 会话层：`lib/session.ts` 提供 `useCurrentUser` 与 `CURRENT_USER_QUERY_KEY`；`components/require-auth.tsx` 在未登录时重定向并保留来源。
- 页面：`components/login-form.tsx`（表现层，登录/注册、提交中、`role="alert"` 错误、键盘可达）；`pages/login.tsx`（容器，登录/注册后写入会话缓存并跳转，已登录直接重定向）。
- 路由：`App.tsx` 新增 `/login`，业务路由统一包在 `RequireAuth + AppShell` 内。
- 导航：`components/app-nav.tsx` 展示当前用户与角色，提供「退出登录」，登出后清会话缓存并回 `/login`。
- 测试：`test-server.ts` 新增 `/api/auth/me|login|register|logout` handlers；新增 `login-form.test.tsx`、`require-auth.test.tsx`、`pages/login.test.tsx`；`App.test.tsx` 等待鉴权完成后再断言外壳。
- Storybook：新增 `.storybook/main.ts`、`.storybook/preview.ts`；`login-form.stories.tsx` 覆盖 Login/Register/Submitting/InvalidCredentials/AccountBanned；package.json 增加 `storybook`、`build-storybook` 脚本，端口可用 `STORYBOOK_PORT` 覆盖。
