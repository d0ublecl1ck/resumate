# 完善用户故事与场景验收

## Background

用户故事目前以功能清单验收，授权与 Full Access、导出与手动提交、取消后的轮次处理存在冲突。需将完整产品需求转化为可追溯的故事、场景与工程约束，补齐开放生态和面试扩展遗漏。

## Scope

- 修订 docs/user-stories/ 全部角色故事，保留原编号可追溯关系，按独立用户结果拆分。
- 新增公共契约与需求覆盖表，统一授权、版本、并发、导出及失败边界。
- 固化产品决策：取消保留有效修改；高影响操作在 Full Access 下仍确认；授权模式创建均需再次确认。
- 补充发现接口、Webhook、SDK、模型路由成本评测、恢复与面试场景。
- 增加求职者 JD 管理：保存、编辑、查找和删除 JD，选择不同简历针对 JD 微调，每个 JD 可软绑定一份简历；绑定不复制或级联修改内容。
- 核对根 README 和项目规则的说明入口；将既有 FREAK 待核查线索迁到根 .freak，规则文件仅保留执行约束。

## Non-goals

- 实现业务接口或页面；替未决产品参数编造数值；变更数据库和公开接口兼容策略。

## Acceptance Criteria

- [x] 每条用户故事有角色、目标、价值以及 Given/When/Then 验收场景。
- [x] 原有 57 条故事全部有修订、拆分或工程需求映射，无遗漏编号。
- [x] 授权、取消、导出、版本聚合在所有文件中一致，三个已确认决策准确落地。
- [x] 产品需求各主题可定位到故事或工程契约，未决项有负责人角色和影响范围。
- [x] 文档链接和故事编号检查通过，无仓库外执行依据引用，archkit inspect . 通过。
- [x] JD 管理、选不同简历微调、每个 JD 至多一个软绑定及删除隔离均有确定契约和验收场景。

## Implementation

- 将原有 57 条故事修订、拆分并补充为 100 条用户故事、201 个 Gherkin 场景；3 条系统故事迁为工程约束，原 ID 在 coverage.md 全量映射。
- contracts.md 统一授权表、模式固化、Working Copy、取消保留修改、并发幂等、手动缓冲与导出边界；D-01～D-05 集中记录需要冻结的产品参数。
- coverage.md 覆盖产品各主题，补充 Webhook、能力发现、双 SDK、Provider 路由成本评测、Resume+JD 面试与笔试题。
- Epic 15 增加 7 条 JD 管理故事；C-13 定义每个 JD 至多一个软绑定、选择不同简历直接或复制后微调、显式换绑与删除隔离，备份覆盖 JD 及绑定关系。
- 逐项修正语义复核的 6 个问题：Agent 恢复仍在本轮单次聚合内、对话确认不另开任务轮、首版实际文案单独审阅、撤销权限后冻结草稿、自动保存场景明确开关前提、双岗位四类题库纳入必加验收。
- 根 README 增加需求入口；AGENTS.md 的 FREAK 线索迁至 .freak，保留既有 generic 门禁范围提醒并增加参数冻结检查。
- 审查了根、ui、backend、quality-gates 的 README 与 docs/design.md：本次只改变需求文档，现有启动、接口实现和架构说明保持适用，无需同步为目标架构。项目无独立记忆文件需更新。

```bash
node --input-type=module <<'JS'
import assert from 'node:assert/strict';
import fs from 'node:fs';
import path from 'node:path';
import {execFileSync} from 'node:child_process';
const root = 'docs/user-stories';
const roles = ['jobseeker.md', 'admin.md', 'agent.md'];
const base = '6823395c0016cf62b7dbd45ecbd6f25ac33b655e';
const ids = new Set();
let scenarios = 0;
for (const file of roles) {
  const text = fs.readFileSync(path.join(root, file), 'utf8');
  const stories = [...text.matchAll(/^### (US-\d+\.\d+) (.+)【(P0|P1|EXT)(?:，必加)?】\n([\s\S]*?)(?=^### |^## |$(?![\s\S]))/gm)];
  assert.equal(stories.length, [...text.matchAll(/^### US-/gm)].length, file);
  for (const [, id, , , body] of stories) {
    assert(!ids.has(id), `重复编号 ${id}`);
    ids.add(id);
    assert.match(body, /^作为.+，我希望.+，以便.+。/m, id);
    const blocks = [...body.matchAll(/```gherkin\n([\s\S]*?)\n```/g)];
    assert(blocks.length > 0, `缺少场景 ${id}`);
    for (const [, block] of blocks) {
      const cases = block.split(/^Scenario: /m).slice(1);
      assert(cases.length > 0, id);
      for (const scenario of cases) {
        for (const step of ['Given', 'When', 'Then']) {
          assert.equal([...scenario.matchAll(new RegExp(`^${step} `, 'gm'))].length, 1, `${id}/${step}`);
        }
        scenarios++;
      }
    }
  }
}
const old = new Set(roles.flatMap(file => [...execFileSync('git', ['show', `${base}:${root}/${file}`], {encoding: 'utf8'}).matchAll(/^### (US-\d+\.\d+)/gm)].map(m => m[1])));
const coverage = fs.readFileSync(path.join(root, 'coverage.md'), 'utf8');
const mapped = [...coverage.matchAll(/^\| (US-\d+\.\d+) \|/gm)].map(m => m[1]);
assert.equal(old.size, 57);
assert.equal(mapped.length, 57);
assert.equal(new Set(mapped).size, 57);
for (const id of old) assert(mapped.includes(id), `遗漏 ${id}`);
let links = 0;
for (const file of [...fs.readdirSync(root).filter(f => f.endsWith('.md')).map(f => path.join(root, f)), 'README.md', 'AGENTS.md', '.freak']) {
  const text = fs.readFileSync(file, 'utf8');
  assert(!/\/Users\/|~\/|\/var\/folders\//.test(text), file);
  assert.equal((text.match(/^```/gm) ?? []).length % 2, 0, file);
  for (const [, href] of text.matchAll(/\[[^\]]*\]\(([^)]+)\)/g)) {
    if (/^(https?:|#)/.test(href)) continue;
    assert(fs.existsSync(path.resolve(path.dirname(file), href.split('#')[0])), `${file}: ${href}`);
    links++;
  }
  for (const [id] of text.matchAll(/US-\d+\.\d+/g)) assert(ids.has(id) || old.has(id), `${file}: ${id}`);
}
console.log({stories: ids.size, scenarios, legacyMappings: mapped.length, links});
