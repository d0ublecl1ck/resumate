# 简历库改为网格卡片布局

## Background

简历库（SCR-002）当前是单列列表：`ui/src/components/resume-library.tsx` 的 `<ul className="grid gap-4">` 只有一列，行组件用左右两栏排布（左侧标题 / 岗位 / 标签 / 关联 JD，右侧保存状态、当前版本、模板 rev、上次编辑），一行占满宽度。简历一多就要长距离滚动，宽屏横向空间被浪费。

改成网格卡片：卡片内垂直排布（顶部标题 + 保存状态、中部元信息、底部操作），保持既有字段与操作不变。

## Scope

- 原型：在 `ui/prototypes/index.html` 注册「设计补充 · SCR-002 简历库（网格卡片）」，登记卡片结构、网格断点与归档 / 复制失败两态。
- `ui/src/components/resume-library.tsx`：列表容器改 `grid gap-4 lg:grid-cols-2 xl:grid-cols-3`（左侧栏固定宽，两列从 1024 起才放得下四个操作）；行组件改卡片，操作区用 `mt-auto` 贴底使同排卡片等高；操作区压成一行（次级操作去掉图标、`px-2.5`、`gap-1.5`）；版本号加截断避免三列下溢出。
- 保留既有行为：打开编辑、版本历史、复制、归档 / 恢复、归档徽标、复制失败就地 `role="alert"`、空态。
- Storybook：`Pages/Resumes` 增加多份简历的 story，供确认网格密度。
- `.freak` 记录「简历库卡片」与「选择层卡片」为何不共用组件（前者内含操作按钮，后者整卡是按钮）。

## Non-goals

- 不改简历数据、查询、筛选、排序与路由逻辑。
- 不改 `ResumePickerDialog` 的卡片：它是整卡可点的 `<button>`，不能内嵌操作按钮，与简历库卡片故意不抽公共组件。
- 不引入分页 / 虚拟滚动（当前无分页）。

## Acceptance Criteria

- [x] 简历库列表在 `lg` 起两列、`xl` 起三列，同排卡片等高且操作区贴底。
- [x] 操作区在三列宽度下保持一行不折行（已在 1024 / 1280 / 1400 宽度实测）。
- [x] 卡片保留标题、保存状态、岗位、标签、关联 JD、当前版本、模板 rev、上次编辑与四个操作。
- [x] 归档徽标、复制失败报错、空态与筛选行为不变。
- [x] `Pages/Resumes` story 覆盖多份简历的网格。
- [x] `pnpm -C ui test`、`pnpm -C ui build`、`pnpm -C ui build-storybook`、`archkit inspect .` 通过。

## Implementation

- `ui/src/components/resume-library.tsx`：容器改 `grid gap-4 lg:grid-cols-2 xl:grid-cols-3`；`ResumeRow` 改名 `ResumeCard` 并改为 `card-soft flex flex-col`，操作区 `mt-auto` 贴底；版本号 `truncate` + `title`；保存状态徽标移到标题行右侧并 `shrink-0`。
- 操作区压成一行：三颗次级操作去掉图标，`px-2.5 py-1.5`、`gap-1.5`。
- 英文文案缩短（两个键只在简历库使用）：`resume.library.openEditor` "Open editor" → "Edit"；`resume.library.versionHistory` "Version history" → "Versions"。原因：英文标签更长，三列宽度下四颗按钮会折行；中文未改。
- 原型：`ui/prototypes/index.html` 新增「设计补充 · SCR-002 简历库（网格卡片）」，登记卡片结构、断点、单行操作区与归档 / 复制失败两态。
- Storybook：`ui/src/pages/resumes.stories.tsx` 新增 `Grid`（6 份样例），用于确认网格密度。
- 测试：`ui/src/components/resume-library.test.tsx` 新增网格容器 / 卡片纵排 / `mt-auto` 契约与归档卡片两态。
