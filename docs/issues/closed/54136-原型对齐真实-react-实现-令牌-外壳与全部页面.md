# 原型对齐真实 React 实现：令牌、外壳与全部页面

## Background

`ui/prototypes/index.html` 停留在 2026-08 的营销首页：胶囊导航 topbar + hero + 工作台 panel，令牌是 hex（`--ink` / `--paper` / `--coral` / `--radius:20px` + 硬阴影），页面只有若干「设计补充」登记段。

真实应用是登录后的工作台：`AppShell` 左侧栏 256px（收起 72px）+ `main` `max-w-6xl`，令牌是 oklch 且带 `.dark`，卡片是 `card-frame`（1.5px 前景色描边）/ `card-soft`（1px border），`App.tsx` 有 16 条路由。

两者在令牌、外壳、页面覆盖三处全面错位，导致 `AGENTS.md`「页面开发以原型为准」这条规则实际无法执行——原型描述的界面在应用里根本不存在。

## Scope

- 重建 `ui/prototypes/index.html`，方向是**原型跟随实现**：
  - 令牌逐值复制 `ui/src/index.css`（含 `.dark`），不再自造 hex 调色板与硬阴影。
  - 外壳对齐 `components/app-shell.tsx` 与 `components/app-nav.tsx`：256px 侧栏、72px 收起、`MobileNav`、主导航 5 项 + 管理员分区（按 RBAC 权限）、用户卡与退出。
  - 组件语法按 `ui/src` 的 Tailwind 组合下沉：`card-frame` / `card-soft` / 按钮三档 / 输入 / chip / 状态徽标（DES-007）/ 统一状态块（DES-012）/ 筛选条（DES-010）。
  - 页面按 `App.tsx` 的 16 条路由逐条登记，每屏附关键状态清单。
- 侧栏只写一份 `<template>`，脚本注入到每个 `[data-shell]`，按 `data-active` 标记当前项。

## Non-goals

- 不改任何 `ui/src` 实现：这是「原型对齐实现」，不是「实现对齐原型」。
- 不追求穷举每屏所有分页状态；关键状态用清单登记，细节状态仍由 Storybook 承载。
- 不引入 CDN 或构建步骤：原型保持单文件、离线可开。

## Acceptance Criteria

- [x] 原型令牌与 `ui/src/index.css` 逐值一致（含 `.dark`）。
- [x] 原型外壳与 `AppShell` / `AppNav` 一致（宽度、断点、导航项、管理员分区、用户卡）。
- [x] `App.tsx` 的 16 条路由在原型中都有对应屏。
- [x] 原型打开无脚本错误，侧栏按屏注入并正确标记当前导航项。
- [x] `archkit inspect .` 通过；`pnpm -C ui test` 与 `build` 不受影响。

## Implementation

- `ui/prototypes/index.html`：整体重写为单文件设计参考，结构为「设计令牌 → 组件语法 → 应用外壳 → 16 条路由的页面屏 + 每屏状态清单」。
- 令牌段直接复制 `index.css` 的 `oklch` 值（light + `.dark`）与 `--radius-lg/xl/2xl`；删掉旧的 hex 调色板（`--ink` / `--paper` / `--coral` / `--cobalt` / `--yellow` / `--line` / `--radius:20px` / 硬阴影 `--shadow`）。
- 外壳段与每屏共用一份侧栏模板（`#tpl-sidebar`）+ 注入脚本，避免 13 处重复。
- 页面屏按 `App.tsx` 路由：`/login`、`/forgot-password`、`/reset-password`、`/verify-email`、`/`、`/resumes`、`/resumes/:id`、`/resumes/:id/versions`、`/jds`、`/jds/:id`、`/profile`、`/settings/*`、`/admin/templates`、`/admin/templates/:id`、`/admin/rbac`、`*`。
- 旧的营销首页与「设计补充」段全部移除；其中仍有价值的状态登记（邮箱验证三态等）并入对应页面屏的状态清单。
- `.freak`：RBAC 两栏未覆盖一条标记为已处理；设置页语言切换一条更新为「原型已重建、该控件仍未登记」；新增「原型是 ui/src 的镜像，改实现要同步改原型」一条。
- 连带同步失效引用：`AGENTS.md` 的「页面开发」两条改为「原型是 ui/src 的镜像，实现落地后必须同步改原型」；`README.md` 的仓库结构与文档索引；`docs/design.md` 的暗色令牌出处；`docs/prd/…屏幕流定义.md` 的 SCR-001 Design Notes 与视觉基线；`settings-layout.tsx` / `login-form.tsx` / `brand/sticker-card.tsx` 三处指向旧原型类名或旧结论的注释。
- 旧原型里的滚动条章节没有丢：并入「组件语法」的 `#scrollbar` 块，`ui/src/index.css.test.ts` 与 `scrollbar.stories.tsx` 的注释引用仍然有效。
