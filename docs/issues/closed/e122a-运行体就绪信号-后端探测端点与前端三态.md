# 运行体就绪信号：后端探测端点与前端三态

## Background

- `agentAvailabilityFromModelConfig` 把 `keyConfigured=true` 一律判成 `runtime_offline`，导致配好模型后助手抽屉仍说「AI 能力尚未接入」并隐藏输入框——当前是假话。
- 后端已能用 `POST /resumes/{id}/runs` 按需 spawn 运行体，但没有就绪探测端点。

## Scope

- 后端：`GET /agent/runtime`（权限 `resume:read`）返回 `{command, available}`；`available = shutil.which(agent_runner_command) is not None`，只探测不执行、不泄露密钥。契约同步。
- 前端：`getRuntimeStatus()`；派生改三态（model_missing / runtime_offline / available），在 `profile-assistant.tsx` 与 `settings-form.tsx` 接同一 query（`useRuntimeStatus`，同 key + staleTime 防重复请求）。
- 测试：三态派生用例；更新依赖旧行为的两处断言为「就绪时显示可对话输入、不显示未接入提示」。

## Non-goals

- 不重整视觉、不新增页面；`AgentAvailabilityNotice` props 形状不变（只改派生函数签名）。
- 不伪造 `available`；`available=true` 仅表示「后端能在需要时启动运行体」，不是已有常驻进程。
- 不合并回 main。

## Acceptance Criteria

- [x] `GET /agent/runtime` 用 `shutil.which` 探测 `agent_runner_command`，返回 `{command, available}`，不执行命令、不含密钥。
- [x] 三态派生：未配置模型 -> model_missing；配置但不可用 -> runtime_offline；配置且可用 -> available。
- [x] profile-assistant 与 settings-form 接同一 runtime query（不重复请求）；就绪时 profile-assistant 显示对话输入且不显示未接入提示。
- [x] `uv run --directory backend pytest -q` 现有 206 不退化；`pnpm -C ui test` 现有 28 files / 215 不退化；`pnpm -C ui build`、`archkit inspect .` 通过。

## Implementation

- 后端：`GET /agent/runtime`（权限 `resume:read`）→ `RuntimeStatusResponse {command, available}`；`service.runtime_status()` 用 `shutil.which(get_settings().agent_runner_command)` 判定，只解析不执行、响应不含密钥（schema 注释写明语义）。
- 契约：§6 端点表新增一行；新增 §20.5「就绪探测」，写明 `available=true` 只承诺「需要时能 spawn」，不承诺模型可用、不承诺已有常驻进程。
- 前端：`types.ts` 加 `RuntimeStatus`；`api.ts` 加 `getRuntimeStatus()`；新增 `lib/runtime.ts` 的 `useRuntimeStatus()`（固定 query key + `staleTime: 30s`），`profile-assistant.tsx` 与 `settings-form.tsx` 共用，避免重复请求。
- 三态派生：`agentAvailabilityFromModelConfig(config, runtime?)`：`keyConfigured=false` → `model_missing`；否则 `runtime?.available ? "available" : "runtime_offline"`。
- 探测中不闪「暂不可用」：两处在 runtime query pending 时不渲染 `AgentAvailabilityNotice`（profile-assistant 同时等 model query）。
- 测试：新增 `agent-onboarding.test.ts`（三态，3 条）；`profile-assistant.test.tsx`、`settings-form.test.tsx` 各加 1 条「就绪时显示对话输入/可用态」正向断言，并把原有「暂不可用」用例改为显式 mock `GET /agent/runtime` 返回 `available:false`。
- 未新增用户可见文案：三态文案复用 `agentOnboarding.state.*`（已由 f7a18d1 重写）。
