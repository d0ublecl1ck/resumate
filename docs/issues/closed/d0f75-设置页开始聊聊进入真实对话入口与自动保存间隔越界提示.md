# 设置页开始聊聊进入真实对话入口与自动保存间隔越界提示

## Background

设置页 SCR-010 有两个已实测缺陷：

1. Agent 运行模式分区的可用性引导按钮「开始聊聊」不会进入任何可对话的地方。`ui/src/components/settings-form.tsx` 的 `onAction` 忽略了 `AgentAvailabilityAction` 参数，无论 `configure_model` 还是 `start_chat` 都只对 `#settings-model-section` 调 `scrollIntoView`——URL 不变，唯一的可观察效果是页面滚动。真实对话入口只有 `/profile` 页头的「对话维护资料」抽屉（`ProfileAssistant` 由 `ProfileWorkspace` 以 `open/onClose` 受控挂载，初始 `false`，当前没有任何 query 参数或外部状态能把它打开）。

2. 「个人偏好 → 自动保存间隔（秒）」越界时没有可见提示。输入 `1` 后原生 `validity.rangeUnderflow=true`，但页面无任何提示、无 `aria-invalid`；保存时 `clampAutosaveSeconds` 静默把它改成 `3`，用户输入被无声改写。合法范围是 `MIN_AUTOSAVE_SECONDS`–`MAX_AUTOSAVE_SECONDS`（`ui/src/lib/autosave.ts`，当前 3–120），后端 `PATCH /settings` 以 `Field(ge=3, le=120)` 返回 422。

## Scope

- `ui/src/components/settings-form.tsx`：`onAction` 按 action 分流；`configure_model` 保持滚到模型配置区，`start_chat` 导航到真实对话入口。
- `ui/src/components/profile-workspace.tsx`：支持 `/profile?assistant=1` 打开页头对话抽屉（关闭时清除该参数）。
- `ui/src/lib/autosave.ts`：新增可复用的范围校验函数 `isValidAutosaveSeconds`。
- `ui/src/components/settings-form.tsx`：自动保存间隔越界时显示可见错误、置 `aria-invalid`、提交前拦截，不再静默夹取；开关关闭时保持禁用。
- `ui/src/i18n/locales/zh-CN/settings.ts` 与 `ui/src/i18n/locales/en/settings.ts`：同步新增错误文案。
- 测试：`ui/src/components/settings-form.test.tsx`、`ui/src/components/profile-workspace.test.tsx`、`ui/src/lib/autosave.test.ts`（如存在则扩展）。
- `ui/prototypes/index.html`：`#screen-settings` 同步越界错误态与 `start_chat` 跳转说明。

## Non-goals

- 不修改 `ui/src/components/profile-assistant.tsx`（该文件由并行 worktree `fix/profile-page-issues` 占用）；其中同类忽略 action 的 `onAction` 记入 `.freak` 遗留。
- 不改后端校验；后端 422 继续作为最终兜底。
- 不新增独立对话页面，不复用简历作用域的 `/resumes/{id}?panel=run`。

## Acceptance Criteria

- [x] 点击「开始聊聊」不触发任何 `scrollIntoView`，而是导航进入真实可发起对话的入口（`/profile?assistant=1` 且对话抽屉打开）。
- [x] 点击「去设置」（`configure_model`）仍滚动到模型配置区，且不导航。
- [x] 自动保存间隔填 `1` 时出现可见错误文案、输入框 `aria-invalid="true"`，点击「保存偏好」不发出 `PATCH /settings` 请求（配置未被改写）。
- [x] 关闭自动保存开关时自动保存间隔输入框仍禁用。
- [x] zh-CN 与 en 词条键结构一致；`pnpm -C ui test`、`pnpm -C ui run build`、`pnpm -C ui run build-storybook`、`archkit inspect .` 全通过。
- [x] 合并到 main 后在真实 5173 用无头 Playwright 复验并截图。

## Implementation

- `ui/src/components/settings-form.tsx`：`onAction` 按 action 分流——`start_chat` 导航到 `/profile?assistant=1`；`configure_model` 与 agent-onboarding 新增的 `retry` 仍滚到 `#settings-model-section`，不再共用同一个滚动动作。
- `ui/src/components/profile-workspace.tsx`：用 `useSearchParams` 读取 `?assistant=1` 初始化并在参数变化时打开 `ProfileAssistant` 受控抽屉；关闭时删除该参数，避免刷新后自动打开。
- `ui/src/lib/autosave.ts`：新增 `isValidAutosaveSeconds(value)`（整数且落在 `MIN_AUTOSAVE_SECONDS`–`MAX_AUTOSAVE_SECONDS`）。
- `ui/src/components/settings-form.tsx` 个人偏好分区：越界时输入框加 `aria-invalid` 与 `aria-describedby`，下方渲染 `role="alert"` 可见错误；「保存偏好」在越界时直接返回、不发请求；payload 不再走 `clampAutosaveSeconds`，改送用户当前输入。关闭自动保存时输入框仍禁用。
- i18n：新增 `settings.preferences.autosaveIntervalError`（zh-CN / en 同步）。
- `ui/prototypes/index.html` 的 `#screen-settings` 补越界错误态与 `start_chat` 分发说明；`.freak` 记录 `profile-assistant.tsx` 同款 `onAction` 遗留。
