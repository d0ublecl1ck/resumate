# 实现 A11 AI 模拟面试闭环并修复全链路 E2E 发现的缺陷

## Background

仓库现有基座是「Profile 存事实、Resume 为岗位投影、JD 记录岗位需求」的可审阅可回滚版本流：FastAPI 后端、Patch/Diff/Working Copy/Version/审批机制、Agent Runtime 与 SSE 轮次事件、PAT 与 RBAC 审计、React 19 前端。此前面试与能力提升能力只在 PRD/Epic 中登记，代码中尚无面试模块。

本次会话实现了 A11《AI 模拟面试与能力提升软件》的面试闭环（题库、计划、题面、作答、报告、成长），并在此后跑了一轮全链路 E2E，修复了版本「恢复到此版本」空实现、RBAC 同级越权、导入预览 duplicate key、8 项 UI 入口缺失、用户管理页缺失、审计时间范围筛选、简历 Markdown 导出、前端改密入口缺失等缺陷。本 issue 用于把上述已完成改动按仓库规矩落成可追溯的提交。

## Scope

- 新增 `backend/app/modules/interview/`（api/dao/llm/models/schemas/service）与迁移 `backend/migrations/versions/c8f1d3a6e2b4_create_interview_tables.py`，并在 `backend/app/main.py`、`backend/migrations/env.py` 装载。
- 新增面试测试 `backend/tests/test_interview.py`、`test_interview_e2e.py`、`test_interview_model.py`、`test_interview_hardening.py`，并扩展 `backend/tests/conftest.py`。
- 新增前端 `ui/src/features/interview/`、`ui/src/pages/interview.tsx`、`interview-session.tsx`、`ui/src/lib/interview.ts`、`ui/src/i18n/locales/*/interview*.ts`，并接入 `App.tsx`、`app-nav.tsx`、i18n index/nav。
- 修复后端 access/auth/profile/resume 模块与前端组件、页面、lib 的 E2E 缺陷：版本恢复、RBAC 同级越权、导入预览 duplicate key、UI 入口缺失、用户管理页、审计时间范围筛选、简历 Markdown 导出、前端改密入口。
- 记录 E2E 证据到 `docs/e2e/2026-10-09/`。

- 面试后端：新增 `backend/app/modules/interview/`（`api.py` / `dao.py` / `llm.py` / `models.py` / `schemas.py` / `service.py` / `__init__.py`）与迁移 `backend/migrations/versions/c8f1d3a6e2b4_create_interview_tables.py`；`backend/app/main.py` 注册路由，`backend/migrations/env.py` 导入模型，`backend/tests/conftest.py` 补面试夹具。
