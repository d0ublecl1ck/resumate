# 系统设置 API 与前端联调

## Background

设置分区（SCR-010 `/settings`）当前只读 mock：`ui/src/lib/api.ts` 的 `getAgentConfig`、`getModelConfig`、`getPreferences` 分别注释为 `GET /agent/config`、`GET /models/config`、`GET /settings`，实现却全部是 `resolve(content.ts 常量)`；`SettingsForm` 字段只读，「测试连接」用 `setTimeout` 假成功，没有任何保存路径。后端没有 settings / agent / model 模块、表或路由。本期补齐持久化 API 并把页面接到真实 HTTP。

## Scope

- 后端新增 `app/modules/settings/`（models/schemas/dao/service/api），按 `api → service → dao → models` 分层，router 在 `app/main.py` 显式注册。
- 端点：
  - `GET /settings`、`PATCH /settings`：个人偏好 theme、language、displayName、autosave、defaultTemplateId、shortcuts。
  - `GET /agent/config`、`PATCH /agent/config`：nextRunMode 与 budget；currentRunMode/modeSource/fullAccessScopes/confirmRetainedOps 为服务端给出的视图字段。
  - `GET /models/config`、`PUT /models/config`：provider、endpoint、model，以及 write-only apiKey。
  - `POST /models/config:test`：连通性测试，响应与错误均不含明文密钥。
- 单用户下按 `owner_id` 幂等创建；`defaultTemplateId` 不可用时显式返回 `defaultTemplateRetired=true`，不静默回退。
- 新增 Alembic 迁移，并在 `migrations/env.py` 导入模型。
- 前端：`ui/src/lib/api.ts` 三个读端点改真实 `request()`，新增保存与测试连接函数；`ui/src/lib/types.ts` 补保存入参与测试结果类型；`SettingsForm` 变为可编辑 + 分区保存 + 真实测试连接状态；`ui/src/test-server.ts` 增加 MSW handlers。
- 同步 `docs/design.md` 端点清单与 `ui/README.md`。

## Non-goals

- 不实现 `/settings/access`（PAT、访问日志、能力发现）与 `/settings/backup`（导入预览），继续保留 mock，另开工单。
- 不实现 Agent 运行时读取该配置生成 Run 快照（属 Agent 模块）。
- 不改页面版式与视觉语言。`ui/prototypes/index.html` 只覆盖首页，未覆盖设置页编辑态；本期只改可交互性并沿用既有组件类，编辑态视觉待补原型后确认。
- 不实现 API Key 落库加密（缺少密钥管理设施），本期只保证服务端私有存储与永不回显。
- 不接入真实认证，沿用 `get_current_user` 单用户占位。

## Acceptance Criteria

- [ ] `GET /settings` 首次访问幂等创建并返回偏好；`PATCH /settings` 部分更新后回读一致。
- [ ] `GET/PATCH /agent/config` 可读并更新 nextRunMode 与 budget，当前 Run 相关字段为只读视图。
- [ ] `PUT /models/config` 可写入 provider/endpoint/model 与 write-only apiKey；任何响应都不含明文密钥，只回 `keyConfigured`。
- [ ] `POST /models/config:test` 返回可理解的成功或失败结果，错误信息不含明文密钥。
- [ ] `defaultTemplateId` 不可用时返回 `defaultTemplateRetired=true`，不静默使用失效默认值。
- [ ] 前端 `/settings` 读取真实后端数据，可修改并保存 Agent 默认模式、模型配置与偏好，刷新后保持一致。
- [ ] 前端保存/测试连接具备 loading、成功、失败状态，失败展示后端错误信息。
- [ ] 后端 `uv run pytest`、前端 `pnpm --dir ui run build|test|lint`、`archkit inspect .` 全部通过。
