# 修正 S4A 源码包排除竞赛材料目录

## Background

`sync-deliverables.sh` 用 `git archive HEAD` 生成 S4A 源码包，脚本自身的验收口径写明「源码包不含 docs/competition/**」。但 `docs/competition/` 在 ef128 里被纳入版本管理后，这条排除实际失效：S4A 包从 36.7 MB 涨到 110.1 MB，把竞赛过程材料（含历史 PPTX 备份与演示视频）一起打了进去。这是实现与验收口径不一致，需要修正。

## Scope

- 修改 `docs/competition/zj-fwwb-2026/sync-deliverables.sh` 的 `git archive` 调用，显式排除 `docs/competition`。
- 重跑同步脚本并确认 S4A 包回到约 36.7 MB；重打桌面提交包（rar）。

## Non-goals

- 不改动其他打包内容与目录结构（除该排除规则外）。
- 不改业务代码、测试与门禁逻辑。
