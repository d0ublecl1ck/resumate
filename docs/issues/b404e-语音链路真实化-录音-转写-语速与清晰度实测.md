# 语音链路真实化：录音、转写、语速与清晰度实测

## Background

`ui/src/features/interview/voice-screen.tsx` 与 `report-screen.tsx` 的「表达维度（语速/清晰度/自信度）」
此前全是写死数字：仓库里没有音频采集、转写或信号处理代码，后端也没有语音接口。
本 Issue 把这条链路做成真实可追溯：录音、转写、按真实时长与真实文本落库计算指标。

## Scope

- 新增后端模块 `backend/app/modules/speech/**`（api → service → dao → models）：
  - `POST /speech/segments`：受理一段作答的语音指标（时长秒、转写文本、可选 sessionId/questionId/pauseCount），服务端计算并落库。
  - `GET /speech/segments?sessionId=`：按会话读回。
  - 表 `speech_segments`；迁移最后创建。
- 前端：
  - `ui/src/features/interview/voice-screen.tsx`：用浏览器 `MediaRecorder` 真实录音并计时；转写优先浏览器 `SpeechRecognition`（Chrome），不可用则明确降级为「手动输入文本 + 手填时长」并如实标注。
  - `ui/src/pages/interview-session.tsx`：增加录音作答入口，录音结果走 `POST /speech/segments` + 既有 `POST /interview/sessions/{id}/answers`。
  - `ui/src/features/interview/report-screen.tsx`：表达维度读真实指标，没有音频记录显示「不适用」，有记录显示真实算出的语速与清晰度。
  - `ui/src/lib/speech-*.ts`：API 客户端、录音 hook/工具、指标汇总纯函数。
  - `ui/src/i18n/locales/{zh-CN,en}/interviewVoice.ts`、`interviewReport.ts`：新增文案，两语言键结构一致。

## Non-goals

- 不新增模型 ASR 接口：当前配置的模型是 OpenAI 兼容的文本 chat completions，无音频转写端点；转写走浏览器 `SpeechRecognition`，不可用时如实降级为手动文本 + 手填时长。
- 不上传原始录音：音频仅本地采集与计时，落库的只有时长、文本与派生指标。
- 不编造自信度「信号实测」：自信度继续沿用「有依据的估计」措辞，不声称来自音频实测。

## Acceptance Criteria

- [x] `POST /speech/segments` 返回并落库 `paceCharsPerMin = round(转写字数 / 时长分钟)`；时长为 0 被 422 拒绝、空转写该值为 null，而不是 0。
- [x] 清晰度用可复核代理指标：口头禅/填充词出现次数 + 可选停顿次数，落库 `clarityScore`/`clarityLevel`。
- [x] `GET /speech/segments?sessionId=` 按属主读回。
- [x] 无音频记录时报告表达维度显示「不适用」；有记录时显示真实算出的语速与清晰度。
- [x] 报告里每个数字都能追溯到一段真实录音与一段真实转写；跑不出真实数据的分支显示「不适用」。
- [x] pytest 覆盖语速计算、空转写、时长为 0 的边界、无音频时报告显示不适用。
- [x] `node quality-gates/run.js` passed；`ui tsc -b --noEmit` 0 error；相关 vitest/pytest 通过。

## Implementation

后端 `backend/app/modules/speech/`（api → service → dao → models）：

- `POST /speech/segments` 受理 `durationSeconds`（必填，`0 < d <= 7200`）、`transcript`、可选 `sessionId/questionId/pauseCount`；
  服务端按「CJK+字母数字」统计字数，`pace = round(字数 * 60 / 时长)`；空文本或不可测时一律返回 `null`。
- 清晰度 = 填充词率（中英白名单命中次数 / 字数）与停顿率（次/分）按文档化常量折算成 0-100 分与
  `good/fair/needs_work`，无文本时为 `null`。自信度不计算，报告继续用「有依据的估计」。
- `GET /speech/segments?sessionId=` 按属主 + 会话读回；`sessionId/questionId` 回指时校验属主。
- 表 `speech_segments`（迁移 `4fd011c03ba5`，`down_revision=a3c5e7f9b1d2`）；`sessionId/questionId` 不建外键，避免跨模块级联。

前端：

- `ui/src/lib/speech-api.ts`：POST/GET 客户端；`ui/src/lib/speech-recorder.ts`：`useVoiceRecorder` 用
  `MediaRecorder` 真实录音计时、Web Audio 静音检测停顿、`SpeechRecognition` 实时转写；`ui/src/lib/speech-metrics.ts`：汇总纯函数。
- `voice-screen.tsx`：接入真实录音/计时/转写；录制不可用或授权被拒时明确降级为「手动输入文本 + 手填时长」并如实标注。
- `interview-session.tsx`：活动题下新增 `VoiceAnswerEntry`（录音 → `POST /speech/segments` → 复用既有
  `POST /interview/sessions/{id}/answers`）；报告表达维度读 `GET /speech/segments`，无记录显示「不适用」。
- `report-screen.tsx`：新增可选 `speech` 入参；有真实指标显示实测值，`speech=null` 显示「不适用」，不再声称自信度来自音频实测。
- i18n：`interviewVoice.ts` 新增 `record.*`，`interviewReport.ts` 新增 `realPaceValue/realPaceBasis/realClarityBasis(+NoPause)/clarityLevels/realNoTranscript`，中英键结构一致。
