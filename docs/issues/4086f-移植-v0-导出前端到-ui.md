# 移植 v0 导出前端到 ui

## Background

v0 平台导出的 Next.js 16 App Router 前端（源目录 /Users/d0ublecl1ck/Documents/resumate）承载了 Resumate 目前最完整的业务界面，但栈与 ui/（Vite + React Router）不一致，无法直接作为产品前端。需要把其中已验证的界面与交互移植进 ui/，替换现存的最小占位壳，同时保留 ui/ 既有工程能力（vitest、msw、oxlint、quality-gates）。

## Scope

- 依赖与底座：ui/package.json 增补 v0 使用的前端依赖，统一 @/* 路径别名，迁入 Tailwind 4 设计令牌，新增 components.json。
- lib 层：复制 utils、types、content、api（api 维持 mock，不接后端）。
- 组件层：kit/* 与业务组件从 Next 迁移到 Vite，删除 "use client"，next/link 换 react-router-dom 的 Link，next/navigation 换 react-router-dom hooks。
- 路由层：App Router 文件树改为 React Router 路由表，[id] 换 :id，async 服务端页面改为同步组件。
- 验证：build、test、lint、archkit inspect . 全绿，并逐条路由实测。

## Non-goals

- 不接入 FastAPI 后端，lib/api.ts 保持 mock 实现。
- 不修改 docs/ 下的 PRD、用户故事与覆盖表（路由口径暂不对齐既有文档）。
- 不改动 backend/。
- 不新增文档原型以外的视觉规则；视觉基线仍以 ui/prototypes/index.html 为准。

## Acceptance Criteria

- [ ] v0 的路由在 ui/ 中全部可访问：/、/resumes、/resumes/:id、/resumes/:id/versions、/jds、/jds/:id、/profile、/settings、/settings/backup、/settings/access、/admin/templates、/admin/templates/:id。
- [ ] pnpm --dir ui run build 通过（tsc -b + vite build）。
- [ ] pnpm --dir ui test 通过，覆盖导航当前态与可访问性。
- [ ] pnpm --dir ui run lint 无告警。
- [ ] archkit inspect . 通过。
- [ ] 浏览器逐条路由实测无控制台报错。
