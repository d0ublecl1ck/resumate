# 新增管理员模板管理与资料复用用户故事

## Background

用户提出两项新需求：1）新增管理员角色，负责配置简历模板；求职者可选择不同模板并流畅渲染预览效果。2）资料管理：求职者的不变信息（姓名、年龄等）应沉淀为资料，基于资料创建适配不同 JD 的简历，避免重复填写。需补充进 docs/user-stories.md。

## Scope

- 用户故事文档新增"管理员"角色定义
- 新增简历模板管理 Epic（管理员配置模板、求职者选模板与实时预览）
- 补充资料复用相关用户故事（基本信息一次维护、创建简历自动带出）


## Non-goals

- None.

## Acceptance Criteria

- [x] 管理员角色与模板管理故事具备验收标准
- [x] 资料复用故事覆盖"不重复填写基本信息"场景
- [x] 与现有 Profile 工程故事边界清晰不重复

## Implementation

更新 `docs/user-stories.md`：角色表新增"管理员"；新增 Epic 6 简历模板管理（US-6.1~6.4：管理员配置/校验模板、求职者流畅切换预览、模板对比）；Epic 7 新增 US-7.2 基本信息一次维护处处复用；US-8.1 补充基本信息自动带出验收点；Epic 6-13 顺延为 7-14 并重排故事编号。
