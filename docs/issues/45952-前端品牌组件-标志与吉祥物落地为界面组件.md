# 前端品牌组件：标志与吉祥物落地为界面组件

## Background

品牌资产已生成并入库（`ui/public/brand/`：`mark.png`、`lockup.png`、`mascot.png`、`mascot-wave.png`，说明见 `ui/public/brand/README.md`），但界面里没有任何位置承接它们：`ui/src/components/app-nav.tsx` 顶栏标志位放的是通用 `Sparkles` 图标，状态块 `ui/src/components/kit/state-block.tsx` 用的是 lucide 图标圆圈，吉祥物完全未使用。

同时界面存在明显的通用生成感，根因有三条：

1. **语法通用**：组件普遍是 1px 中性边框 + 柔和阴影 + `rounded-lg` 的组合，与 `ui/prototypes/index.html` 定稿的贴纸语法（2px 墨边、硬投影、按压缩放位移）脱节。
2. **无人格态**：空态是「圆圈里放一个 lucide 图标」，Agent 是抽象头像，品牌资产无处安放。
3. **无物理感**：原型中 hover 位移 `-2px`、active 位移 `+2px` 与阴影收缩的按压反馈，在应用组件层没有对应实现。

本 Issue 的取向是把品牌资产变成**可复用的界面语法**，而不是往页面里贴插画：每个组件都必须承担信息职责（状态、来源、语气、动作），吉祥物只在「有话说」的位置出现。

## Scope

新增品牌组件目录 `ui/src/components/brand/`，共 5 组组件，全部只依赖既有令牌（`ui/src/index.css`）与既有依赖：

1. `brand-mark.tsx`：`BrandMark` / `BrandLockup`。尺寸 `sm | md | lg`，表面 `paper | dark`；标志位替换占位字符。
2. `sticker-card.tsx`：`StickerCard`。贴纸语法容器：2px 墨边 + 硬投影 + 20px 圆角；`tone`（`paper | cobalt | coral | gold`）、`lift`（`none | sm | md | lg`）、`tilt`（-3..3 度）、`interactive`（按压位移反馈）。
3. `stamp-badge.tsx`：`StampBadge`。盖章式状态戳：旋转、色块填充、带文本；`tone`（`neutral | cobalt | coral | gold`）、`size`。
4. `mascot-note.tsx`：`MascotNote`。吉祥物对话气泡：头像姿态 `hero | wave`、语气 `hint | praise | warn | ask`、尾巴朝向 `start | end`、`pending` 打字中态；替代通用 Agent 头像与灰底提示条。
5. `mascot-state.tsx`：`MascotState`。空 / 加载 / 错误 / 冲突 / 无权限 / 冻结六态，吉祥物姿态 + 一句话 + 一个动作；`size`（`quiet | default | hero`）与 `mascot`（`pose | badge`）构成尺寸与音量两档。

音量与配额（用户已裁决）：默认音量档为 C，即「语法 + 标志徽章」——常规页用 `MascotState mascot="badge"` 与 `MascotNote mascot="badge"`；角色当面出面（`mascot="pose"`）只允许出现在首次空态、Agent 说话处、成功反馈三类位置。

首批替换点（用户已裁决执行）：

- `ui/src/components/app-nav.tsx`：顶栏 `Sparkles` 图标方框改为 `BrandMark size="md"`，字标与链接结构不变。
- `ui/src/components/kit/state-block.tsx`：改为 `MascotState mascot="badge"` 的语义适配层，保留原有 props 与 `alert` 播报契约。

配套：

- 新增 i18n 命名空间 `brand`（`ui/src/i18n/locales/zh-CN/brand.ts` 与 `ui/src/i18n/locales/en/brand.ts`，键结构一致）。
- 每个组件配套 Storybook story，覆盖默认、边界（超长文案 / 多行）、空、加载、错误、禁用态。
- 一个组合 story，把顶栏标志、贴纸卡片、吉祥物提示、盖章状态、品牌空态拼在同一屏，用于判断整体是否仍有生成感。

## Non-goals

- 不接后端、不改路由与业务逻辑、不改页面业务数据。
- 除上列两个已裁决替换点外，不再改动其他既有组件；`ui/src/components/ui/` 不动。
- `StateBlock` 的公开 props 与 `alert` 播报契约保持不变，只替换视觉实现。
- 吉祥物不做无信息职责的装饰堆砌。

- [x] 视觉只用原型既有令牌（墨蓝 / 纸白 / 暖米 / 珊瑚 / 钴蓝 / 柔黄）与既有圆角、边框、投影值，不新增表外颜色或新依赖。
- [x] Storybook 覆盖默认 / 边界 / 空 / 加载 / 错误 / 禁用态，且 `pnpm -C ui build-storybook` 通过。
- [x] `pnpm -C ui test` 通过，`archkit inspect .` 通过。
- [x] 组合 story 能直观看出：标志位、状态、Agent 语气均由品牌语法承载，而非通用图标 + 中性卡片。
- [x] 音量档位可调：`MascotNote mascot=full|badge|none`、`MascotState size=quiet|default|hero`、`MascotState mascot=pose|badge`，并有 `Brand/Mix` 四档对照 story。
- [x] 两个已裁决替换点落地：`app-nav` 用 `BrandMark`，`StateBlock` 改为品牌适配层且既有 props 契约不变。

## Implementation

实际实现与 Scope 的差异，逐条记录：

- `kit/state-block.tsx` 由图标圆圈改为 `MascotState mascot="badge"` 适配层，`kind` 联合类型吸收 `MascotStateKind`（含新增 `conflict`），公开 props 未变。
- `MascotState` 的六态语义不再只靠姿态：徽章档为 `forbidden` / `frozen` 保留降饱和滤镜，为 `error` / `conflict` 保留 `alert` 与珊瑚标题，避免六态退化成同一张图。
- 品牌资产路径收敛到 `ui/src/components/brand/brand-assets.ts` 单一映射（原先在标志与吉祥物两处各写一份）。
- 新增 `brand` 命名空间词条：`brand.volume.*`（四档密度名）与 `brand.state.conflict.*`。
