# 前端品牌组件：标志与吉祥物落地为界面组件

## Background

品牌资产已生成并入库（`ui/public/brand/`：`mark.png`、`lockup.png`、`mascot.png`、`mascot-wave.png`，说明见 `ui/public/brand/README.md`），但界面里没有任何位置承接它们：`ui/src/components/app-nav.tsx` 的标志位仍是占位字符「R」，吉祥物完全未使用。

同时界面存在明显的通用生成感，根因有三条：

1. **语法通用**：组件普遍是 1px 中性边框 + 柔和阴影 + `rounded-lg` 的组合，与 `ui/prototypes/index.html` 定稿的贴纸语法（2px 墨边、硬投影、按压缩放位移）脱节。
2. **无人格态**：空态是「圆圈里放一个 lucide 图标」，Agent 是抽象头像，品牌资产无处安放。
3. **无物理感**：原型中 hover 位移 `-2px`、active 位移 `+2px` 与阴影收缩的按压反馈，在应用组件层没有对应实现。

本 Issue 的取向是把品牌资产变成**可复用的界面语法**，而不是往页面里贴插画：每个组件都必须承担信息职责（状态、来源、语气、动作），吉祥物只在「有话说」的位置出现。

## Scope

新增品牌组件目录 `ui/src/components/brand/`，共 5 组组件，全部只依赖既有令牌（`ui/src/index.css`）与既有依赖：

1. `brand-mark.tsx`：`BrandMark` / `BrandLockup`。尺寸 `sm | md | lg`，表面 `paper | dark`；标志位替换占位字符。
2. `sticker-card.tsx`：`StickerCard`。贴纸语法容器：2px 墨边 + 硬投影 + 20px 圆角；`tone`（`paper | cobalt | coral | gold`）、`lift`（`none | sm | md | lg`）、`tilt`（-3..3 度）、`interactive`（按压位移反馈）。
3. `stamp-badge.tsx`：`StampBadge`。盖章式状态戳：旋转、色块填充、带文本；`tone`（`neutral | cobalt | coral | gold`）、`size`。
4. `mascot-note.tsx`：`MascotNote`。吉祥物对话气泡：头像姿态 `hero | wave`、语气 `hint | praise | warn | ask`、尾巴朝向 `start | end`、`pending` 打字中态；替代通用 Agent 头像与灰底提示条。
5. `mascot-state.tsx`：`MascotState`。空 / 加载 / 错误 / 无权限 / 冻结五态，吉祥物姿态 + 一句话 + 一个动作；替代 `kit/state-block.tsx` 的图标圆圈（不删除既有组件，仅提供品牌态替代）。

配套：

- 新增 i18n 命名空间 `brand`（`ui/src/i18n/locales/zh-CN/brand.ts` 与 `ui/src/i18n/locales/en/brand.ts`，键结构一致）。
- 每个组件配套 Storybook story，覆盖默认、边界（超长文案 / 多行）、空、加载、错误、禁用态。
- 一个组合 story，把顶栏标志、贴纸卡片、吉祥物提示、盖章状态、品牌空态拼在同一屏，用于判断整体是否仍有生成感。

## Non-goals

- 不接后端、不改路由与业务逻辑、不替换现有页面。
- 不改 `ui/src/components/ui/` 与既有 `kit/` 组件的行为；本次只新增。
- 吉祥物不做无信息职责的装饰堆砌。

## Acceptance Criteria

- [ ] `ui/src/components/brand/` 下 5 组组件可独立渲染，props 与状态覆盖完整。
- [ ] 所有用户可见文案走 i18n 键；新增 `brand` 命名空间，zh-CN 与 en 键结构一致，en 资源无中文残留。
- [ ] 视觉只用原型既有令牌（墨蓝 / 纸白 / 暖米 / 珊瑚 / 钴蓝 / 柔黄）与既有圆角、边框、投影值，不新增表外颜色或新依赖。
- [ ] Storybook 覆盖默认 / 边界 / 空 / 加载 / 错误 / 禁用态，且 `pnpm -C ui build-storybook` 通过。
- [ ] `pnpm -C ui test` 通过，`archkit inspect .` 通过。
- [ ] 组合 story 能直观看出：标志位、状态、Agent 语气均由品牌语法承载，而非通用图标 + 中性卡片。
