# 开放接入与备份 API 联调

## Background

一期把 `/settings` 主页面接到真实 HTTP，但 `/settings/access`（PAT、访问审计、能力发现）与 `/settings/backup`（备份导出与导入预览）仍是 `content.ts` mock：PAT 创建/撤销是纯前端状态、审计表格是假数据、备份导出按钮无处理、导入预览是固定样例。本期为这两个分区补齐持久化 API 并完成联调。

## Scope

- access 模块：`personal_access_tokens` 与 `access_logs` 表；`GET /access/tokens`、`POST /access/tokens`（返回一次性 `secretOnce`，库中只存哈希）、`POST /access/tokens/{id}/revoke`、`GET /access/logs`、`GET /.well-known/resume-agent` 能力发现。
- 令牌状态按到期时间计算 active/expiring/revoked；创建与撤销写入审计日志。
- backup 模块：`GET /backup/export`（权威 JSON）、`GET /backup/export/markdown`（可读索引）、`POST /backup/import:preview`（校验并预览）、`POST /backup/import`（确认导入为新资源并重映射 ID）。
- 前端：access 面板接真实创建/撤销并刷新；backup 面板接真实导出下载、上传校验预览与确认导入。
- 迁移与 `docs/design.md` 同步。

## Non-goals

- 不做 PAT 的请求鉴权强制（scope 校验、Bearer 中间件），归认证工作流；本期只做签发、撤销与展示。
- 不做证据附件存储与下载，附件列表暂为空。
- 不实现跨用户导入。

## Acceptance Criteria

- [ ] `POST /access/tokens` 返回 `secretOnce` 且列表接口不再返回该明文；数据库只存哈希。
- [ ] `POST /access/tokens/{id}/revoke` 后状态为 revoked，重复撤销幂等；创建与撤销各产生一条审计日志。
- [ ] `GET /.well-known/resume-agent` 返回契约版本与能力列表。
- [ ] `GET /backup/export` 返回含 profiles/resumes/resumeVersions/jobDescriptions 的 JSON；Markdown 索引可读。
- [ ] `POST /backup/import:preview` 合法备份返回 valid 与 ID 映射；缺失引用返回 has_issues 并列出问题；非法格式 422。
- [ ] `POST /backup/import` 导入后资源数增加、ID 全部重映射、绑定关系恢复。
- [ ] 前端 PAT 创建显示一次性凭证、撤销后列表更新；备份导出下载可用、上传后展示真实预览。
- [ ] 后端 pytest、前端 build/test/lint、`archkit inspect .` 全部通过。
