# 开放接入与备份 API 联调

## Background

一期把 `/settings` 主页面接到真实 HTTP，但 `/settings/access`（PAT、访问审计、能力发现）与 `/settings/backup`（备份导出与导入预览）仍是 `content.ts` mock：PAT 创建/撤销是纯前端状态、审计表格是假数据、备份导出按钮无处理、导入预览是固定样例。本期为这两个分区补齐持久化 API 并完成联调。

## Scope

- access 模块：`personal_access_tokens` 与 `access_logs` 表；`GET /access/tokens`、`POST /access/tokens`（返回一次性 `secretOnce`，库中只存哈希）、`POST /access/tokens/{id}/revoke`、`GET /access/logs`、`GET /.well-known/resume-agent` 能力发现。
- 令牌状态按到期时间计算 active/expiring/revoked；创建与撤销写入审计日志。
- backup 模块：`GET /backup/export`（权威 JSON）、`GET /backup/export/markdown`（可读索引）、`POST /backup/import:preview`（校验并预览）、`POST /backup/import`（确认导入为新资源并重映射 ID）。
- 前端：access 面板接真实创建/撤销并刷新；backup 面板接真实导出下载、上传校验预览与确认导入。
- 迁移与 `docs/design.md` 同步。

## Non-goals

- 不做 PAT 的请求鉴权强制（scope 校验、Bearer 中间件），归认证工作流；本期只做签发、撤销与展示。
- 不做证据附件存储与下载，附件列表暂为空。
- 不实现跨用户导入。

## Acceptance Criteria

- [x] `POST /access/tokens` 返回 `secretOnce` 且列表接口不再返回该明文；数据库只存哈希。
- [x] `POST /access/tokens/{id}/revoke` 后状态为 revoked，重复撤销幂等；创建与撤销各产生一条审计日志。
- [x] `GET /.well-known/resume-agent` 返回契约版本与能力列表。
- [x] `GET /backup/export` 返回含 profiles/resumes/resumeVersions/jobDescriptions 的 JSON；Markdown 索引可读。
- [x] `POST /backup/import:preview` 合法备份返回 valid 与 ID 映射；缺失引用返回 has_issues 并列出问题；非法格式 422。
- [x] `POST /backup/import` 导入后资源数增加、ID 全部重映射、绑定关系恢复。
- [x] 前端 PAT 创建显示一次性凭证、撤销后列表更新；备份导出下载可用、上传后展示真实预览。
- [x] 后端 pytest、前端 build/test/lint、`archkit inspect .` 全部通过。

## Implementation

- 后端 access：`app/modules/access/`（models/schemas/dao/service/api），`personal_access_tokens` 与 `access_logs` 两表；PAT 明文只在创建响应返回 `secretOnce`，库中只存 SHA-256 哈希与前缀。
- 令牌状态按到期窗口计算 active/expiring/revoked；重复撤销幂等；创建与撤销各写一条审计日志（`purpose` 存 `token_create`/`token_revoke` 稳定键，前端映射文案）；`GET /.well-known/resume-agent` 基于 `request.base_url` 返回契约版本与能力列表。
- 后端 backup：`app/modules/backup/` 以 `resumate-backup/1.0` JSON 为权威载荷；`GET /backup/export`、`GET /backup/export/markdown`、`POST /backup/import:preview`、`POST /backup/import`。预览校验格式版本与引用完整性并产出 ID 映射/绑定恢复/缺失引用；导入新建资源并重映射 ID。
- 校验约束：`profiles.owner_id` 唯一，导入时复用已存在的 Profile 容器、事实作为新行写入；非法格式返回 422 `VALIDATION_FAILED`。
- 迁移 `d4b8e2a6f1c9_create_access_tables.py`；`main.py` 注册 access/backup router；`migrations/env.py`、`conftest.py` 导入 access 模型。
- 前端：`api-client.ts` 新增 `requestText`；`api.ts` 接入 PAT 签发/撤销/列表、审计日志、能力发现与备份导出/Markdown/预览/导入；`access-panel.tsx` 增加创建（名称+scope，创建后显示一次性凭证）与撤销 mutation；`backup-panel.tsx` 支持真实导出下载、上传校验预览、确认导入与结果提示；`settings-access.tsx` 变更后刷新，`settings-backup.tsx` 去掉 mock 查询。
- i18n 集成：合并 main 的 i18next 双语迁移与 `ui-i18n` 门禁；后端 `fullAccessScopes`/`confirmRetainedOps`/`shortcuts[].action`/审计 `purpose` 改为稳定键；新增 `settings` 命名空间词条（zh-CN/en 键结构一致）；`settings-form.tsx` 以 main 的 i18n 版本为基础重写并保留可编辑分区保存与真实测试连接。
- 文档：同步 `docs/design.md`（表、目录、端点、关键决策）与 `ui/README.md`。
