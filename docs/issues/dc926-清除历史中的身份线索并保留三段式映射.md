# 清除历史中的身份线索并保留三段式映射

## Background

公开仓库的历史里仍含学校名、教师名、真实姓名、作者句柄与个人邮箱等身份线索（内容与提交元数据都有）。用户要求把这些线索在全部 git 历史中替换为占位并强推；同时要保留可追溯性：仓库已有 pre-LFS → post-LFS 的两段映射表，本轮改写后需要升级为三段式。

## Scope

- 用 `git filter-repo` 对全部 refs 做替换：内容用 `--replace-text`、提交信息用 `--replace-message`，并把作者/提交者里的作者句柄与个人邮箱替换为占位。
- 替换规则放在 /tmp，不进入仓库。
- 把 `docs/history-commit-map.tsv` 升级为三段式：`original_sha` / `after_lfs_sha` / `final_sha` + `subject`。
- 改写前先建 mirror 备份到仓库外。

## Non-goals

- 不改业务代码与测试、门禁逻辑。
- 不动第三方 mock URL `github.com/zhangmu`（仓库既有口径：5dbc7 明确保留）。
