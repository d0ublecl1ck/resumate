# 按角色拆分用户故事文档

## Background

docs/user-stories.md 单文件较长，用户希望按角色拆分到 docs/user-stories/ 目录，便于按角色查阅。

## Scope

- 按角色拆分：求职者、管理员、Agent/系统（内置 Agent、外部 Agent、系统）
- 新建 docs/user-stories/ 目录与索引 README
- 删除原单文件 docs/user-stories.md

## Non-goals

- None.

## Acceptance Criteria

- [x] 每个故事只出现在一个角色文件中，无遗漏无重复
- [x] 索引 README 含角色文件导航、优先级汇总与 Non-goals

## Implementation

拆分 `docs/user-stories.md` 为 `docs/user-stories/`：`jobseeker.md`（47 个故事）、`admin.md`（2 个）、`agent.md`（5 个，含系统与外部 Agent 视角），索引 `README.md` 含导航、角色定义、优先级汇总与 Non-goals；原单文件删除。

## Verification

- 故事总数 54 = 47+2+5，与拆分前一致，无遗漏无重复。
- `archkit inspect .` 通过。
