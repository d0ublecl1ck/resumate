# 用户故事：管理员

P0 为 MVP，P1 为增强。管理员维护模板资源，不因此获得求职者私人资料访问权。共同验收依据为[公共契约](contracts.md)。

## Epic 6：模板管理

### US-6.1 创建可复用模板【P0】
作为维护模板库的管理员，我希望定义布局、样式、分页和导出配置，以便求职者可选择完整可用的版式。
```gherkin
Scenario: 保存模板草稿
Given 我已获得模板管理权限
When 我保存包含布局、样式、分页与导出配置的有效模板
Then 模板以草稿状态保存，可继续编辑但不出现在求职者可选列表
Scenario: 无管理权限
Given 当前账户只有求职者权限
When 该账户请求新增模板
Then 系统拒绝操作，模板库保持不变
```

### US-6.2 预览并校验模板边界【P1】
作为准备发布模板的管理员，我希望使用边界样例检查排版，以便避免求职者导出残缺文件。
```gherkin
Scenario: 检查长内容与空章节
Given D-03 已冻结长内容、空章节、自定义章节和多页样例
When 我对草稿模板运行预览校验
Then 系统逐样例展示预览与溢出、截断、分页问题及对应位置
Scenario: 修复后复验
Given 校验报告指出某个章节溢出
When 我保存布局修正并重新校验
Then 系统更新该模板修订的校验结果，旧报告不被当作新修订通过证明
```

### US-6.5 发布模板【P0】
作为维护模板库的管理员，我希望发布已准备好的模板，以便求职者可以选择它。
```gherkin
Scenario: 发布有效模板
Given 模板必需配置和渲染校验通过，启用的边界检查无未解决错误
When 我确认发布该模板修订
Then 系统生成可引用的模板版本并加入可选列表，记录发布操作者与时间
Scenario: 无效模板阻止发布
Given 模板缺少必要配置或渲染失败
When 我请求发布
Then 系统指出具体错误，模板仍为草稿且不进入可选列表
```

### US-6.6 下架模板并保留已有简历【P0】
作为维护模板可用性的管理员，我希望停止新选用某模板，以便更新模板库而不影响用户已有成果。
```gherkin
Scenario: 下架已有引用模板
Given 模板已被若干简历使用
When 我确认下架
Then 新简历不能选择它，已有简历仍可按原模板版本预览和导出
Scenario: 重新上架
Given 模板已下架且其发布版本仍有效
When 我确认重新上架
Then 该模板重新出现在求职者的可选列表
```

### US-6.7 删除未使用的模板【P0】
作为清理模板库的管理员，我希望删除无用模板，以便减少维护负担。
```gherkin
Scenario: 删除无引用模板
Given 模板没有任何简历引用且删除摘要已展示
When 我确认删除
Then 该模板从模板管理列表移除，操作可审计
Scenario: 保护被引用模板
Given 模板存在简历引用
When 我请求删除
Then 系统拒绝物理删除并提供下架入口，已有渲染不受影响
```

### US-6.8 更新模板而不改变已投递样式【P0】
作为持续改进模板的管理员，我希望新修订与已使用版本分开，以便发布改进时保留旧简历呈现。
```gherkin
Scenario: 编辑已发布模板
Given 模板 V1 已被简历 A 使用
When 我保存模板布局修改
Then 系统产生待发布修订，A 仍引用 V1 且排版保持不变
```
