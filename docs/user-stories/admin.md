## Epic 6：简历模板管理

### US-6.1 管理员配置简历模板【P0】
作为管理员，我希望创建和维护简历模板（布局、样式、分页与导出配置），以便求职者有高质量、风格多样的模板可选。
- [ ] 模板 CRUD：新建、编辑、上下架、删除
- [ ] 模板定义覆盖布局、样式、分页和导出配置
- [ ] 下架模板不影响已使用该模板的简历渲染


### US-6.2 管理员预览与校验模板【P1】
作为管理员，我希望用示例数据预览模板渲染效果并校验分页溢出，以便发布前确认模板质量。
- [ ] 模板编辑时实时预览
- [ ] 对长内容、空章节等边界数据校验渲染结果
