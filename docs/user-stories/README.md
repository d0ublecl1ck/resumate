# Resumate 用户故事（按角色拆分）

> 来源：《Resumate：对话式简历编辑系统》产品文档。

## 文件导航

| 文件 | 覆盖角色 | 内容 |
| --- | --- | --- |
| [jobseeker.md](jobseeker.md) | 求职者 | 简历管理、对话编辑、Diff、版本、导出、模板选择、Profile、执行模式、设置、AI 面试 |
| [admin.md](admin.md) | 管理员 | 简历模板配置与校验 |
| [agent.md](agent.md) | 内置/外部 Agent、系统 | Agent Runtime、版本聚合系统行为、开放生态接入 |

## 角色定义

| 角色 | 说明 |
| --- | --- |
| 求职者 | 使用系统创建、编辑、导出简历的终端用户 |
| 内置 Agent | 系统自带的对话式编辑 Agent（公共 API 的参考客户端） |
| 外部 Agent | 用户自带的 Hermes、Codex、Claude 等 Agent，经开放接口接入 |
| 面试官 Agent | 比赛扩展中驱动模拟面试的 AI 面试官 |
| 管理员 | 负责配置简历模板与平台级资源的运营角色 |

## 优先级汇总

| 优先级 | 覆盖范围 |
| --- | --- |
| P0 | Epic 1–13 主体：简历工程、Agent、Profile、开放生态、执行模式、版本聚合 |
| P1 | 多对话恢复、语义比较增强、导入抽取、Provider 路由成本统计、Webhook |
| EXT | Epic 14：AI 面试四必加模块 + 题库生成 |

## 明确不做（Non-goals）

- 复杂多 Agent 编排
- 自动投递与招聘网站账号操作
- Git 仓库作为简历存储
- 企业多租户复杂权限
- 实时文生视频数字人（本期数字人/DDS 表现层非必加）
