## 为什么有些提交物不在这里

- `S4A-源码包.zip`：由 `git archive HEAD` 打包并对包内副本做占位替换后生成，是可复现产物，由交付同步脚本产出，不重复入库。
- `本地知识库资料.zip`：由仓库内知识库语料（`backend/app/modules/kb/corpus/`）与索引说明生成脚本打包，是可复现产物，由交付同步脚本产出，不重复入库。

## 维护约定

- 本目录只放已定稿、可直接提交的成品；任何一次重新导出后，请同步更新本文件的字节数与 sha256。
- 成品由本地交付工程导出，源工程未纳入本仓库；仓库内只保留成品快照与本说明。
